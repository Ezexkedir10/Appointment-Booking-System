# AppointIQ Studio

AppointIQ Studio is an upgraded appointment booking system built as a premium operations dashboard for service businesses. It extends the original internship project into a stronger portfolio product with a redesigned interface, richer business data, and more realistic operational workflows.

## What This Version Adds

- Premium multi-page product shell with a more polished SaaS-style interface
- Persistent local workspace data using browser storage
- Advanced appointment tracking with booking channel, payment state, location, and lifecycle status
- Service catalog with categories, buffers, capacity, featured offerings, and visual identity
- Provider management with specialties, utilization targets, ratings, and workload visibility
- Client relationship management with segmentation, tags, preferred contact method, and lifetime value context
- Availability planning with provider schedule windows and utilization views
- Control-room dashboard focused on revenue, upcoming work, retention mix, and operating capacity

## Core Routes

- `/` overview and product landing
- `/dashboard` analytics and control room
- `/appointments` booking pipeline management
- `/services` service catalog design
- `/providers` team operations
- `/clients` client relationship management
- `/availability` scheduling capacity planning

## Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS 4
- Radix UI
- Lucide icons

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Portfolio Positioning

This project is designed to present an appointment-booking system as a more advanced business platform rather than a simple CRUD demo. It focuses on product depth, interface quality, and operational realism so it can support stronger CV and GitHub presentation.
